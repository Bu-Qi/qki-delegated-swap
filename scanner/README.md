# QKI 套利扫描器 1.0.1

本地界面程序，支持 USDT 闭环和原生 QKI 入场的 WQKI 闭环。读取实时池子、按余额计算参考投入、完整模拟含税兑换，再用真实钱包地址直接调用 Router 做最终验证。只把扣除 Gas 后达到设定最低净收益的候选列入结果。

## Windows 启动

1. 安装 **Node.js 20 或更新版本**（[官方下载](https://nodejs.org/)）。
2. 下载此项目 ZIP 并**完整解压**，不要直接在压缩包预览中运行。
3. 双击项目根目录的 **`start-scanner-windows.cmd`**，也可进入 `scanner` 双击 `start-windows.cmd`。首次启动会检查并安装锁定版本的依赖，随后自动打开 `http://127.0.0.1:3847`。
4. 保持启动窗口开启。通过浏览器钱包连接 QKI，或直接填写用于只读扫描的钱包地址。

此版本为本地浏览器界面，使用电脑浏览器的钱包扩展确认交易。运行时只需要 Node.js 和 npm；无需部署检测合约。程序不是独立的 Windows EXE。

### 启动失败或窗口闪退

1.0.1 的 Windows 入口使用 ASCII、CRLF 和常驻命令窗口；Node.js 缺失时直接在窗口提示。Node 入口会检查完整解压、版本和实际依赖加载，并把子进程的原始错误留在窗口和日志中。

Windows 启动日志保存在 `%LOCALAPPDATA%\QKIArbitrageScanner\startup.log`，缓存保存在同目录的 `data` 文件夹。日志的确切位置也会打印在窗口中。如果仍不能启动，请保留窗口最后几行或该日志末尾的错误信息。端口被占用时，窗口会给出已运行界面的地址。

macOS/Linux：进入 `scanner` 文件夹运行 `sh start.sh`。已在项目根目录安装依赖时，也可执行 `npm run scanner:start`。

## 使用

- **快速重算**：更新全部池子和余额，重新求内置/已发现路径的参考投入并再次模拟。首次使用也可运行，适合先检查常见路径。
- **全面扫描**：在所列 Factory 内遍历 3–6 跳简单闭环，再按跳数和第一跳分散挑选候选模拟。遍历上限为每个基础资产 1,200 万分支；触及上限会在导出结果的 `scope.truncated` 标记，不保证全链穷尽。
- **模拟数量上限**：限制候选执行检查次数；它不代表完整遍历的路径数量。默认共 400 个候选，最终用新快照复核至多 40 条。
- **Gas**：默认 500 Gwei，可调整。Gas 上限以估计值增加 20%；USDT 路线把 QKI Gas 费用按当前 USDT/WQKI 池的 `getAmountsIn` 折成 USDT。不同币种的净收益不相加。
- **QKI 路线**：实际调用 `swapExactQKIForTokensSupportingFeeOnTransferTokens`，输入原生 QKI、收到 WQKI；净收益另含 75,000 Gas 的赎回预留并加 20%。WQKI 余额会展示，当前入口使用原生 QKI。
- **复核交易**：检查连接钱包、余额、授权、实际输出和 Gas，再展示完整地址、投入、最低输出与费用。复核有效期 60 秒；在你点击打开钱包前再次检查同一笔交易，参数不会静默替换。
- **USDT 授权**：需要授权时，界面提供对固定 Router 的明确额度授权，额度为最大 USDT 投入与当前余额的较小值。未经 Router 授权的候选不标记为已验证交易。
- **成交后重算**：读取到成功或回退回执后，自动更新池子。不会按旧报价自动再次提交，也不自动签名。
- **赎回 WQKI**：余额区可将当前 WQKI 赎回为 QKI，先展示确切数量和 Gas，再由钱包确认；这是独立的一笔交易。
- **导出 JSON**：含完整地址路径、参考投入、模拟输出、最低输出、Gas、净收益、区块和共享池子信息。

同池路线往往只是同一价差的不同变体，收益不能相加。每次成交都可能使原路线变成亏损。交易最低输出同时保护滑点、投入本金、费用折算预算和设定的最低净收益；实际交易仍取决于上链时状态，失败交易会消耗 Gas。

## 固定网络与模拟方式

| 项目 | 配置 |
|---|---|
| Chain ID | 20181205 |
| Router | `0x3c91FD5247B050A1536F24D012a17a618EEFbfCA` |
| Factory | `0x4cB5B19e8316743519072170886355B0e2C717cF` |
| WQKI | `0x835F6dF988B6f51c9477D49e96aDBbc644ba97a2`，18 位 |
| USDT | `0xDF0e293CC3c7bA051763FF6b026DA0853D446E38`，6 位 |
| 参考池手续费 | 997/1000，每次启动与 Router 样例计算核对 |

自动节点选择包含已有的 11 个 QKI RPC；也可手动输入 HTTP/HTTPS 节点。节点须支持 `eth_call` 状态覆盖。持有人必须是普通钱包地址；不支持把合约钱包当成可直接签名的普通账户。

检测步骤只覆盖临时代码和经过 getter 验证的 USDT 持有人→检测器授权，**不覆盖任何原生币或代币余额**。USDT 使用指定合约已验证的授权槽 5；布局不匹配立即停止。最终 Router 的 `eth_estimateGas` 和 `eth_call` 使用实际地址、余额和现有授权，**不使用状态覆盖**。代币税、黑名单和 K 校验失败会被筛除。

失败方向会用于本轮候选优先级调整，下一轮重新观察；失败不等同于该方向在所有地址、金额和时间下永远不可交易。未经测试的高报价不会显示为已验证收益。

这里的 USDT 指该 QKI 链代币的数量，不表示已验证美元兑付或跨链兑换能力。报告是快照和参考金额，不保证含税后的全局最优投入。

## 命令行

```sh
cd scanner
npm ci --omit=dev
node cli.mjs --owner 0x你的地址 --quick --gas 500
node cli.mjs --owner 0x你的地址 --tests 400 --hops 6 --out result.json
node server.mjs --port 3848 --no-open
```

直接运行 server/CLI 时，`data/cache.json` 保存已发现路径，`data/latest-report.json` 保存最近一次完成的结果；Windows 启动器使用上述用户数据目录。它们仅保存在运行电脑，不提交到仓库。停止扫描立即终止工作进程；未完成结果不会用于复核。窗口关闭会停止扫描，已提交到钱包的链上交易仍需在钱包核对。

后端仅开放只读 RPC 方法，钱包签名与广播由浏览器扩展在明确点击后完成。服务只监听 `127.0.0.1`，限制 Host/Origin，并使用一次性交易复核。钱包切换、网络变化、参数变化、重新扫描或超时都会使旧复核失效。

## 开发和验证

在项目根目录：

```sh
npm ci
npm run scanner:build
npm run scanner:test
```

构建只生成 `probe.json`，不会部署合约。编译器固定 Solidity 0.8.24、优化 200、viaIR、EVM Paris。测试覆盖金额与精度、逆向费用折算、Gas 预算、最低输出、实际余额、授权不足、QKI 原生入口、过期/一次性复核和本地 API 边界。

界面交互测试：在 `scanner` 目录执行 `npm ci` 后运行 `node test/ui-smoke.mjs`。使用模拟钱包验证取消、参数变更和异步复核失效，不发送交易。

`seed-paths.json` 只包含基础资产和地址路径，供首次快速重算；不含历史利润、持有人余额或执行保证。所有金额和可执行性都在运行时重新计算。
